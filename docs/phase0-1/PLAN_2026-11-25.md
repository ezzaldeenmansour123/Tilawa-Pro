## 1. الرؤية والهوية

**تلاوة** تطبيق واحد يجمع القراءة والاستماع والحفظ والتعلم والتفسير والتدبر، لسبع فئات: القارئ، الحافظ، المتعلم، المستمع، الباحث عن التفسير، الأطفال والمبتدئون، غير الناطقين بالعربية.

**الهوية غير القابلة للتنازل:**
1. مجاني — بلا إعلانات، بلا اشتراكات، بلا حساب إجباري.
2. Offline-First — الوظائف اليومية الأساسية تعمل دون إنترنت. الإنترنت فقط عند ضغطة تنزيل صريحة من المستخدم، أو طلب تحديث.
3. خصوصية — لا رفع تسجيلات صوتية، لا تحليلات خارجية، لا تتبع، لا Speech-to-Text سحابي، لا API خارجي للبحث أو التفسير اليومي.
4. صغير الأساس — APK الأساسي 50–70 ميغابايت (الحالي 70.1 ميغابايت، والهدف بعد تقسيم المعالجات ≈ 48 ميغابايت). كل شيء كبير حزمة اختيارية بحجم معلن قبل تنزيلها.
5. صحيح علمياً — لا تفسير مولَّد يُعرض كتفسير عالم، لا فتوى آلية، لا حكم تصحيح صوتي قاطع دون مستوى ثقة، ولا خلط بين روايات.
6. لا تضحية بالأداء من أجل كثرة الميزات — كل ميزة جديدة تمر باختبار أداء وذاكرة وبطارية.

**التموضع التنافسي:** Tarteel يفوز في التسميع لكنه مدفوع (12.99 دولار/شهر) ويحتاج إنترنت. Quran.com يفوز في القراءة النظيفة المجانية لكن بلا تسميع ذكي. Al Quran يفوز في كثرة الترجمات والقرّاء دون إنترنت. تلاوة تفوز بجمع الثلاثة: **تسميع ذكي مجاني دون إنترنت + مصحف كامل دون إنترنت + تفسير وترجمة — بلا إعلانات.**

## 3. الخريطة المعمارية

### 3.1 تقسيم `main.dart` — الهدف: لا ملف فوق ~400 سطر

```
lib/
  main.dart            # bootstrap فقط (~120 سطراً)
  core/
    settings.dart      # الإعدادات
    user_data.dart     # بيانات المستخدم + ترحيل SharedPreferences ← SQLite
    theme.dart         # هوية باستيل: سكري / أزرق فاتح / وردي فاتح جداً / أخضر هادئ + ليلي
    router.dart        # Shell + تنقل سفلي
    download_manager.dart  # مدير الحزم: إيقاف/استكمال/تحقق SHA/مساحة (جديد)
    connectivity.dart  # مؤشر حالة الاتصال والمحتوى المحلي — بلا تتبع (جديد)
  data/
    db.dart            # يُقسَّم: schema.dart + search.dart + tafsir.dart
    migrations.dart    # ترحيلات مرقّمة + user_meta(schema_version) (جديد)
    packages.dart      # سجل الحزم المثبتة وحجومها (جديد)
  features/
    reader/            # فهرس السور، قارئ السورة، تفاصيل الآية
    mushaf/            # صفحات المصحف: عرض صفحة كاملة + مزامنة الموضع (جديد)
    audio/             # AudioService + مشغل + قوائم + تنزيلات
    tajweed/           # TajweedEngine: بيانات الأحكام + تلوين + مفتاح ألوان (جديد)
    memorization/      # خطة حفظ + مراجعة متباعدة + اختبارات (جديد)
    speech/            # واجهة محرك محلي + مستوى ثقة (جديد)
    tafsir/            # متصفح تفسير + مقارنة + أسباب نزول
    search/            # بحث عربي محترف
    academy/           # دروس + نورانية + أطفال (جديد)
    translation/       # ترجمات + transliteration (جديد)
    words/             # بطاقة الكلمة: معنى/جذر/إعراب/مواضع (جديد)
    user/              # مفضلة، سجل، ورد، مكتبة، إعدادات
  tools/
    build_db.py        # كما هو + إضافة تجويد وكلمات وترجمات عند توفر مصادر مرخصة
    build_packages.py  # توليد حزم اختيارية + manifest بالحجوم وSHA-256 (جديد)
    make_icon.py       # كما هو
test/
  db_test.dart / search_test.dart / audio_test.dart
  tajweed_test.dart / memorization_test.dart
```

**قواعد:** كل ميزة في مجلدها بلا استيراد دائري؛ `features/*` لا تستورد بعضها إلا عبر `core/`؛ منطق البحث والصوت والحفظ قابل للاختبار دون واجهة؛ يُحذف `rm -rf test` من CI ويُستبدل ببوابة `flutter test` تمنع الدمج عند الفشل.

### 3.2 ترحيل قاعدة البيانات دون فقد بيانات المستخدم
1. جدول `user_meta(key, value)` فيه `schema_version` (يبدأ 1) + `lib_sha`.
2. كل ترحيل مرقَّم كدالة `migrate_1_to_2()` مع اختبار وحدة، يُطبَّق مرة واحدة عند أول فتح بعد التحديث.
3. نقل المفضلة والملاحظات والوسوم والسجل والختمة من SharedPreferences إلى جداول SQLite في الترحيل الأول، مع نسخة احتياطية من ملف JSON القديم قبل الحذف، وتصدير/استيراد JSON يملكه المستخدم.
4. `needsUpdate()` الموجود يبقي سلوكه: مقارنة SHA للـ DB المدمجة بالمثبتة، واستبدال ذري (ملف مؤقت + إعادة تسمية) فقط بعد تحقق SHA. لا حذف لمحتوى مثبَّت عند تحديث التطبيق.

### 3.3 نظام الحزم الاختيارية السبع

| الحزمة | المحتوى | الحجم التقديري | في APK؟ |
|---|---|---|---|
| 0. الأساسية | Flutter + DB الحالية (قرآن + 3 تفاسير) + أميري | 50–70 MB (الهدف بعد تقسيم المعالجات ≈ 48 MB) | نعم |
| 1. صفحات المصحف | تخطيط نصي من DB (<1 MB)؛ أو صور 604 إن رُخِّصت | نصي <1 MB؛ صور ≈ 600 MB بدقة عالية | لا — عند الطلب |
| 2. القراء | لكل قارئ: سورة ≈ 5–30 MB؛ قرآن كامل ≈ 300–900 MB حسب الجودة | يُعرض قبل التنزيل | لا — عند الطلب |
| 3. التفاسير | ابن كثير / الطبري / القرطبي، كل تفسير حزمة مستقلة | كل واحد ≈ 10–25 MB نص + FTS (يُؤكَّد) | لا — عند الطلب |
| 4. نموذج التسميع | yazinsai خفيف 25 MB / كامل 68 MB (+ ONNX Runtime) | 25–68 MB | لا — عند الطلب، مع حالة «غير مثبَّت» |
| 5. الدروس | تجويد + نورانية + أطفال (نص + صوت أمثلة) | ≈ 5–20 MB | لا — عند الطلب |
| 6. الترجمات | Sahih International + لغات أخرى، كل لغة حزمة | كل لغة ≈ 1–3 MB | لا — عند الطلب |

**قواعد الحزم:** عرض الحجم قبل التنزيل؛ إيقاف/استكمال؛ تحقق SHA-256؛ عرض المساحة المستخدمة والمتبقية؛ لا تنزيل تلقائي إطلاقاً.

## 4. المخطط التفصيلي حسب الأقسام الـ15

### القسم 1 — المصحف الإلكتروني المتكامل

**1أ. مصحف المدينة (604 صفحات) — الأولوية: التخطيط النصي أولاً، الصور بعد الترخيص**
- عرض الصفحة كاملة كما في المصحف الورقي، لا آية منفصلة في وضع المصحف. توزيع الآيات وعلامات الوقف محفوظان من `ayahs.page` (1..604) الموجود في DB.
- تكبير/تصغير الصفحة، ملء الشاشة، سحب بين الصفحات، انتقال مباشر لرقم صفحة، انتقال لسورة/جزء/حزب، فهرس سور وأجزاء وأحزاب.
- حفظ آخر صفحة وموضع القراءة تلقائياً، علامات مرجعية متعددة، عودة لآخر موضع.
- الوضع الليلي للصفحات فقط إذا توفرت نسخة مناسبة — وإلا يبقى التخطيط النصي مع ثيم ليلي.
- **مصدر الصور:** مولّد `quran/quran.com-images` من خطوط مجمع الملك فهد — قانوني من حيث المبدأ (الحق المحفوظ الوحيد: الطباعة الورقية داخل المملكة للبيع التجاري) لكن ≈ 600 MB — تنزيل اختياري فقط، **لا يُضمَّن في APK أبداً**. إن لم يُحسم الترخيص، يُكتفى بالتخطيط النصي.
- **قبول:** 604 صفحات تطابق الترقيم؛ اختبار انتقال سورة/صفحة/جزء؛ مزامنة الموضع بين وضع الصفحات ووضع النص.

**1ب. وضع القراءة المتصل — موجود جزئياً، يُكمَّل**
- خط عربي واضح (أميري)، تكبير/تصغير الخط، تحكم بالمسافات بين السطور، وضع ليلي، تحديد آية، مشاركة ونسخ الآية، انتقال بين الآيات، عرض تفسير الآية ومعاني كلماتها.
- **يُضاف:** تلوين التجويد (القسم 2)، بطاقة الكلمة (القسم 6).
- مزامنة موضع القراءة بين الوضعين قدر الإمكان (آخر آية ← رقم صفحتها والعكس).

### القسم 2 — نظام التجويد الاحترافي

**الأحكام (رواية حفص عن عاصم أساساً، بلا خلط روايات):** الإظهار الحلقي، الإدغام بغنة وبغير غنة، الإقلاب، الإخفاء الحقيقي، أحكام النون والميم المشددتين، الإخفاء الشفوي، الإدغام الشفوي، الإظهار الشفوي، المد الطبيعي والمتصل والمنفصل واللازم والعارض للسكون ومد البدل ومد الصلة، القلقلة، التفخيم والترقيق، أحكام الراء، أحكام لام لفظ الجلالة، أحكام الوقف والابتداء.

**لكل حكم:** لون واضح، اسم الحكم، تعريف مبسط، مثال قرآني، استماع لمثال صوتي، شرح طريقة النطق، إظهاره عند الضغط عليه. ومفتاح ألوان يشرح كل لون.

**الأوضاع:** عرض جميع الأحكام، إظهار حكم محدد، وضع التعلم، استماع مع متابعة الأحكام، إخفاء الألوان للقراءة العادية.

**المصدر الموثَّق:** `cpfair/quran-tajweed` برخصة **CC BY 4.0** — آمن للتضمين مع الإسناد. 18 قاعدة، 60,057 نطاقاً. ملاحظتان: إزاحاته مبنية على نص تنزيل ca. 2017 لا v1.1 الحالي — يلزم محاذاة قبل الدمج؛ وبديل أحدث `quran-ws/quran-tajweed` v0.4.2 يحتاج فحصاً قبل اعتماده. **محظور للتضمين الدائم:** تجويد Quran.com API (عرض فقط، تخزين ≤ أسبوع).
**قبول:** كل حكم له لون واسم وتعريف ومثال؛ اختبار تطابق الأحكام مع المصدر.

### القسم 3 — منظومة الصوتيات والتلاوات

**القراء — الهدف المعلن 17 مكتملاً لا 20 (موثَّق):**
الموجودون 7: العفاسي، الحصري، عبد الباسط، المنشاوي، السديس، المعيقلي، الشريم.
الإضافيون الكاملون الموثَّقون آيةً بآية من EveryAyah (10): الشاطري، فارس عباد، ياسر الدوسري، هاني الرفاعي، ناصر القطامي، علي جابر، عبد الله بصفر، أحمد العجمي، سعد الغامدي (40kbps فقط — جودة منخفضة)، صلاح البدير.
**لا يُضاف كمكتمل:** مصطفى إسماعيل (جزئي: 2017 من 6236 ملفاً)، إدريس أبكر (غير موجود — تسجيله الكامل غير مكتمل أصلاً)، تسجيل مشترك سديس+شريم نقي (غير موجود في هذين المصدرين — الموجود فقط مع ترجمة). البديل لقارئين يُقرره المستخدم من قائمة EveryAyah الكاملة الموثقة، لا من الذاكرة.
**الترخيص:** EveryAyah بلا شروط منشورة (UNKNOWN)؛ islamic.network أوضح — إعادة توزيع مجاني غير تجاري مسموحة مع بقاء الحقوق للقرّاء وخطر طلب إزالة. التوصية: islamic.network أولاً حيث يتوفر آيةً بآية (الشاطري، العجمي، الرفاعي، بصفر)، وEveryAyah للباقين، مع شاشة نسبة تذكر القارئ والمصدرين، وعدم تعديل التسجيلات، وعدم تضمين ملفات في APK. **لا أسماء وهمية ولا تسجيلات تجريبية، والتحقق من اكتمال السور لكل قارئ قبل إظهاره كمكتمل.**
**الجودة:** لا تُفرض 64kbps. الجودات المتاحة 16–192kbps حسب المجلد (العفاسي 128، عبد الباسط المرتل 192) — خيارات تنزيل متعددة للجودة إذا توفرت.

**المشغل (مستوى احترافي):** تشغيل/إيقاف مؤقت/استئناف/إيقاف كامل، التالي/السابق آيةً، شريط تقدم زمني قابل للسحب، تحكم بمستوى الصوت، سرعات 0.5x و0.75x و1x و1.25x و1.5x و2x إذا دعمها المحرك بجودة مناسبة، تكرار آية واحدة ومجموعة آيات وسورة ومقطع بعدد مرات محدد، انتقال تلقائي بين الآيات، اختيار قارئ وسورة وبداية ونهاية مقطع، تشغيل متواصل، مؤقت إيقاف تلقائي، تشغيل في الخلفية، تحكم من شاشة القفل والإشعارات، حفظ آخر موضع استماع، قائمة تشغيل مخصصة، مفضلة، سجل استماع، استكمال بعد إغلاق التطبيق، دعم Bluetooth وأزرار التحكم الخارجية وشاشة السيارة عند التوافق.
**التنزيل دون إنترنت:** سورة واحدة، مجموعة سور، جزء، قرآن كامل لقارئ محدد — مع اختيار الجودة، إيقاف واستكمال، حذف، عرض مساحة مستخدمة، إدارة ملفات، تحقق من اكتمال الملفات وسلامتها. لا تنزيل كامل إجباري. التنزيل الحالي هشّ (حلقة بلا استئناف والفشل يُبتلع بصمت) — يُعاد بناؤه في مدير الحزم.
**متابعة الكلمات:** تظليل الآية الحالية (موجود عبر `currentAyahId`)، وتظليل الكلمة الحالية **فقط عندما تتوفر بيانات توقيت دقيقة** — لا توقيتات عشوائية ولا تخمينات. مزامنة نص/صوت، انتقال للكلمة المستمع إليها، انتقال لموضع الضغط في النص.

### القسم 4 — المحفظ الذكي بالذكاء الاصطناعي (أهم محور تنافسي)

**المحرك — الحكم: ALLOWED-WITH-CONDITIONS، لكن لا مسار Flutter رسمي.**
- الكود MIT؛ أوزان 1.x (`spliced-clean`) **CC BY 4.0** — الكاملة 67.8 MB والخفيفة 24.7 MB + مرجع 4.7 MB، بشرط النسبة واستخدام 1.x فقط والبقاء مجانياً على الميزة. قيد NPL-1.2 يخص أصول 0.x/Quran-Lab فقط ولا ينطبق على 1.x.
- الحدود حرفياً: معاينة `1.0.0-rc.1`، يكشف أخطاء الحفظ فقط (لا تجويد ولا نطق بعد، ولا حدر ولا أصوات أطفال)، حفص فقط، دقة 90.3% والتقاط 87.5%، و7 من 13 شريط إصدار فقط تمر.
- **العائق الأكبر:** المنصات المدعومة ويب وNode وReact Native تجريبي غير مُتحقق على الأجهزة — لا Flutter/Android أصلي، وأداء الهاتف غير مقيس إطلاقاً. **يلزم PoC (2–3 أسابيع) قبل الالتزام:** WebView تستضيف `@tilawa/core/web`، أو إعادة تنفيذ Dart عبر ONNX طرف ثالث، أو RN التجريبي. إن فشل PoC، يُؤجَّل التسميع أو يُستبدل — ولا يُدَّعى اكتماله.
- شروط الدمج: 1.x فقط؛ الميزة مجانية بالكامل؛ نسبة «Tilawa (tilawa.dev)» + tlog وQUD وmuaalem وquran-transcript وicefall وTanzil؛ تحقق SHA-256؛ تضمين النموذج والمرجع محلياً (استضافة ذاتية)؛ وصفه كمساعد حفظ فقط؛ الصوت على الجهاز فقط؛ أي ميزة مدفوعة أو إعلانات أو تبديل لأصل Quran-Lab يقلب الحكم إلى BLOCKED فوراً.

**وضع التسميع:** يختار المستخدم السورة أو المقطع ثم يضغط بدء التسميع. النظام يستمع عبر الميكروفون، يتعرف على الآيات، يحدد موضع القارئ، يتتبع الكلمات، يقارن القراءة بالنص، ويكتشف الكلمات المحذوفة والمستبدلة والزائدة، ويحدد موضع الخطأ ويعرض التصحيح، ويتابع القراءة بعد التصحيح.
**واجهة الأخطاء:** الكلمات الصحيحة بلون طبيعي، المحذوفة موضحة في موضعها، المستبدلة مع عرض الصحيح، الزائدة محددة، إظهار الآية التي وصل إليها المستخدم، مؤشر تقدم الحفظ، إعادة المحاولة. **لا يُعتبر التردد أو التوقف القصير خطأ تلقائياً** — ويستطيع المستخدم إعادة الكلمة أو الآية. **مستوى ثقة للنظام، وإذا لم يكن متأكداً فلا يصدر حكماً قاطعاً.**
**أوضاع الحفظ:** اختبار آية واحدة، مجموعة آيات، صفحة، وجهين، سورة كاملة، موضع عشوائي، نهاية الآية، أوائل الآيات، المتشابهات، إخفاء النص بالكامل، إظهاره عند طلب المساعدة، كشف الخطأ أثناء التسميع.
**المراجعة الذكية (محلية):** الآيات المتقنة والضعيفة وكثيرة الأخطاء، الكلمات المتكررة الأخطاء، تاريخ آخر مراجعة، عدد مرات النجاح والإخفاق. خوارزمية مراجعة متباعدة تحدد موعد إعادة كل آية. المستويات: جديد، سبق حفظه، قيد المراجعة، متقن، يحتاج مراجعة عاجلة.
**خطة الحفظ:** هدف يومي وأسبوعي، مقدار حفظ ومراجعة، متابعة إنجاز، تقارير أسبوعية، إحصائيات تقدم، مشاركة التقرير مع المعلم أو الشيخ — **دون رفع التسجيلات الصوتية عند مشاركة التقرير.**

### القسم 5 — أكاديمية تعليم القرآن والتجويد

**تعليم التجويد:** دروس منظمة — مقدمة، أحكام النون الساكنة والتنوين، أحكام الميم الساكنة، المدود، القلقلة، التفخيم والترقيق، مخارج الحروف، صفات الحروف، أحكام الراء، الوقف والابتداء. كل درس: شرح واضح، أمثلة قرآنية، تسجيلات صوتية، مقارنة بين النطق الصحيح والخاطئ، اختبار قصير، نسبة إنجاز.
**تعليم المبتدئين:** الحروف الهجائية، الحركات، السكون، الشدة، التنوين، المدود، تركيب الكلمات، قراءة الكلمات القرآنية.
**القاعدة النورانية:** منهج منظم بمحتوى مرخَّص فقط — لا محتوى بلا ترخيص.
**وضع الأطفال:** واجهة مبسطة، أحرف كبيرة، ألوان مريحة، دروس قصيرة، أمثلة صوتية بطيئة، تدريبات تفاعلية، متابعة تقدم الطفل. بلا إعلانات وبلا محتوى غير مناسب.

### القسم 6 — معاني القرآن والبحث اللغوي

**بطاقة الكلمة (عند الضغط على أي كلمة):** معناها، شرح مبسط، الجذر اللغوي، نوع الكلمة، الإعراب إذا توفر مصدر موثوق، مواضع ورود الكلمة في القرآن، الآيات المرتبطة بها.
**البحث:** كلمة قرآنية، جذر لغوي، عبارة، موضوع، معنى، اسم سورة، رقم آية.
**إصلاح البحث العربي (إلزامي في Phase 0):** الواو والفاء والباء والكاف واللام، أل التعريف، اختلاف أشكال الهمزة، الألف المقصورة والياء، التشكيل، البحث الجزئي. **دون تغيير النص القرآني الأصلي** — التطبيع في حقل منفصل فقط. الخطة من التدقيق (§3): تطبيق تجريد البادئات نفسه على طرف الاستعلام، وتقييد التجريد أحادي الحرف (لا تجريد إلا إذا كان الباقي يبدأ بـ «ال» أو طوله ≥ 5 أحرف — يمنع `انت ← كانت` و`سم ← بسم`)، ونقل بحث التفاسير إلى عمود FTS نفسه بدل `LIKE`. اختبارات انحدار إلزامية: `بالصلاة` و`والمؤمنين` و`فالغيب` و`للصابرين` يجب أن تعيد نتائج؛ و`انت` و`سم` و`تابا` يجب ألا تعيد «كانت/بسم/كتابا».
**المصادر:** الصرف من Quranic Arabic Corpus (GPL — نسخ وتوزيع حرفي، التغيير غير مسموح، إسناد، غير تجاري/بحثي فقط) — ممكن بشروط. **الإعراب الكامل محظور:** تغطية 40% فقط (السور 1–8 و59–114) — لا يُعرض كإعراب كامل.

### القسم 7 — التفسير والتدبر

**التفاسير:** ابن كثير، الطبري، القرطبي — مع تنزيل كل تفسير حزمة مستقلة. لا تُجعل جميعها جزءاً إجبارياً من APK. **المصدر:** QuranLab بعد قراءة `LICENSES.md` لكل config (QF API لا يسمح بالتضمين الدائم — عرض فقط وتخزين ≤ أسبوع). ومعرّف القرطبي 90 غير موثَّق — يُعاد التحقق من `/resources/tafsirs` قبل أي استخدام.
**مقارنة التفاسير:** عند فتح آية — عرض ابن كثير والطبري والقرطبي، مقارنة تفسيرين جنباً إلى جنب، اسم المؤلف والمصدر، انتقال للآية التالية والسابقة.
**أسباب النزول:** من مصادر موثوقة مع توضيح مصدر كل رواية ودرجة ثبوتها عند توفرها.
**البحث الموضوعي:** فهرس يشمل الصبر، الرزق، الرحمة، التوبة، الصلاة، الأخلاق، بر الوالدين، الأنبياء، الجنة والنار، الإيمان، المعاملات، الأسرة — مع انتقال للآيات المرتبطة بكل موضوع.
**التدبر:** آية اليوم، سؤال للتأمل، ملاحظات شخصية، دفتر تدبر، حفظ الآيات المفضلة، ربط الآيات المتشابهة، تصنيف الملاحظات. **تمييز واضح بين النص القرآني والتفسير والملاحظات الشخصية.**

### القسم 8 — الترجمة العالمية

1. الترجمة الإنجليزية أولاً: **Sahih International** — ليست ملكاً عاماً ولا CC؛ استعمال غير تجاري حرفي مع الإسناد ورابط Tanzil، ويُنصح بإذن كتابي من Saheeh International / Dar Abul-Qasim.
2. إمكانية إضافة لغات أخرى (كل لغة حزمة ≈ 1–3 MB).
3. الكتابة الصوتية اللاتينية (transliteration) للنص العربي.
4. عرض الترجمة تحت كل آية، وإظهارها عند الضغط على الآية.
5. البحث باللغة الإنجليزية.
6. تنزيل الترجمات دون إنترنت.
7. تغيير لغة واجهة التطبيق.
**لا تُقدَّم الترجمة باعتبارها بديلاً عن النص القرآني العربي.**

### القسم 9 — المفضلة والتنظيم الشخصي

الآيات المفضلة، العلامات المرجعية، قوائم قراءة، قوائم استماع، ملاحظات شخصية، سجل قراءة، سجل استماع، سجل حفظ، سجل اختبارات، إحصائيات استخدام، نسخ احتياطي واستعادة. **بيانات المستخدم محلية افتراضياً** (SQLite بعد الترحيل من SharedPreferences)، مع خيار تصديرها واستيرادها بصيغة JSON يملكه المستخدم.

### القسم 10 — التصميم وتجربة المستخدم

**الهوية البصرية:** الأبيض السكري، درجات الأزرق الفاتح، الوردي الفاتح جداً للتفاصيل الثانوية، الأخضر الهادئ للعناصر القرآنية، ألوان داكنة متناسقة للوضع الليلي. تصميم راقٍ بسيط احترافي، بلا ازدحام بصري ولا ألوان مبالغ فيها، مريح للعين عند القراءة الطويلة. الهوية الحالية (باستيل) تُحافَظ عليها وتُهذَّب، لا تُستبدل عشوائياً.
**الصفحة الرئيسية (8 عناصر فقط، لا كل الميزات):** متابعة القراءة، آخر موضع قراءة، الاستماع، الحفظ والتسميع، تعلم التجويد، التفسير والتدبر، البحث، المكتبة.
**التنقل:** شريط تنقل سفلي واضح يضم الأقسام الرئيسية؛ كل قسم واجهة منظمة خاصة به؛ الوصول للمصحف والتلاوة والحفظ سريع. التنقل الحالي (3 تبويبات: الرئيسية/المكتبة/المزيد) سيزدحم مع نمو الأقسام — يُعاد تصميمه في Phase 2 قبل إضافة الأقسام.
**إمكانية الوصول:** دعم أحجام الخطوط، قارئات الشاشة، أزرار كبيرة مناسبة لكبار السن، تباين مناسب، دعم RTL العربي وLTR للغات الأخرى. لم يُدقَّق وصول التطبيق الحالي — يحتاج اختباراً.

### القسم 11 — البنية التقنية (إلزامي)

كما في §3 أعلاه: 12 وحدة مستقلة، SQLite + FTS5، فهارس مناسبة، سرعة استعلام، تخزين محلي، إدارة تنزيلات، عدم تكرار البيانات، ترحيل مرقَّم عند التحديث.
**يعمل محلياً دون إنترنت:** قراءة القرآن، صفحات المدينة بعد توفيرها محلياً، التفاسير المنزَّلة، الترجمات المنزَّلة، البحث في المحتوى المحمل، الحفظ والاختبارات، متابعة التلاوة بنموذج محلي مناسب، الملاحظات والعلامات المرجعية، الدروس المحملة، التلاوات المحملة. الإنترنت فقط لجلب المحتوى والتحديثات والتنزيلات الاختيارية. **لا يتوقف التطبيق عند انقطاع الإنترنت.**

### القسم 12 — الأداء والحجم

كما في §3.3: الحزم السبع، عرض حجم كل حزمة قبل تنزيلها، إدارة مساحة وتخزين مؤقت، **لا تنزيل إجباري لنموذج الذكاء الاصطناعي على جميع المستخدمين.** هدف APK الأساسي 50–70 MB.

### القسم 13 — الاختبارات وضمان الجودة

لا تنتهي المهمة بنجاح البناء. اختبارات فعلية قبل كل إصدار:

**اختبارات القرآن:** تطابق عدد السور 114، عدد الآيات وفق رواية المصحف المعتمدة، مطابقة نصوص القرآن مع مصدر موثوق، التحقق من صفحات المصحف الـ604، اختبار الانتقال بين السور والصفحات.
**اختبارات الصوت:** جميع القراء، تشغيل السور، السرعات، التكرار، التنزيل، الخلفية، استعادة موضع التشغيل.
**اختبارات الحفظ:** كلمة صحيحة، كلمة ناقصة، كلمة مستبدلة، كلمة زائدة، التوقف والتردد، الضوضاء، اختلاف سرعة القراءة، استمرار التتبع.
**اختبارات البحث:** كلمات مشكولة، دون تشكيل، بالسوابق، بالجذور، جزئي، نتائج عربية — بما فيها اختبارات انحدار §6 أعلاه.
**اختبارات الأداء:** استهلاك الذاكرة، البطارية، سرعة فتح المصحف، سرعة البحث، أداء الصوت، أداء نموذج الذكاء الاصطناعي.
**اختبار العزل عن الإنترنت (إلزامي):** بعد تثبيت التطبيق وتنزيل المحتوى اللازم — افصل Wi-Fi، أوقف بيانات الهاتف، افتح التطبيق من جديد، اختبر المصحف والبحث والتفسير والتلاوات المحملة وأدوات الصوت والتسميع والحفظ والمراجعة وجميع الوظائف المحلية. يجب أن تستمر طبيعياً. وافحص اتصالات التطبيق الصادرة أثناء التشغيل للتأكد من عدم وجود اتصالات خلفية غير مصرح بها.

### القسم 14 — قواعد صارمة لا يجوز تجاوزها

1. لا تخترع بيانات قرآنية.
2. لا تستخدم ملفات غير موثوقة.
3. لا تعرض تفسيراً مولداً بالذكاء الاصطناعي على أنه تفسير عالم.
4. لا تقدم فتاوى آلية.
5. لا تعرض نتائج تصحيح صوتي غير مؤكدة على أنها أخطاء قطعية.
6. لا تضع ميزات وهمية أو أزراراً لا تعمل.
7. لا تكتب أن الميزة تعمل دون إنترنت قبل اختبارها فعلياً بعد قطع الاتصال.
8. لا تستخدم مصادر صوتية أو نصوصاً دون مراجعة تراخيصها.
9. لا تحذف الميزات الموجودة دون سبب تقني واضح.
10. حافظ على بيانات المستخدم.
11. حافظ على توافق التطبيق مع النسخة السابقة إن أمكن.
12. لا تغيّر applicationId أو مفتاح التوقيع الأصلي دون ضرورة وموافقة. (ملاحظة: المفتاح الحالي debug فقط — إنشاء keystore إصدار جديد خارج المستودع يحتاج موافقتك، وتغيير التوقيع يعني إعادة تثبيت لا تحديثاً تلقائياً.)
13. لا تضع مفاتيح API أو أسرار التوقيع داخل مستودع GitHub.
14. لا تضف خدمات مدفوعة إلزامية.
15. لا تضف إعلانات.

### القسم 15 — Offline-First (شرط أساسي غير قابل للتنازل)

**التشغيل الأول:** يعمل ويفتح دون إنترنت، بلا حساب إجباري، بلا اتصال إجباري، بلا رسالة تطلب الاتصال لمجرد فتح التطبيق. يمكن استخدام المحتوى والميزات المتوفرة محلياً.
**الوظائف المحلية (كلها دون إنترنت):** المصحف كاملاً، صفحات المدينة الـ604 بعد توفيرها محلياً، البحث، ألوان التجويد، التفسير المنزَّل، معاني الكلمات، الإعراب والجذور المتوفرة محلياً، الترجمة المحملة، تشغيل التلاوات المحملة وجميع أدوات مشغل الصوت، التسميع والتعرف بنموذج محلي، اكتشاف أخطاء الحفظ التي يدعمها المحرك، الاختبارات، خطط الحفظ، المراجعة المتباعدة، دروس التجويد المحملة، وضع الأطفال، الملاحظات والمفضلة، الإحصائيات والتقارير، حفظ بيانات المستخدم.
**الإنترنت عند الطلب فقط:** (1) ضغطة تنزيل قارئ أو سورة، (2) تنزيل تفسير، (3) تنزيل نموذج ذكاء اصطناعي، (4) تنزيل دروس أو ترجمات إضافية، (5) بحث عن محتوى غير موجود محلياً، (6) التحقق من تحديث التطبيق، (7) نسخ احتياطي سحابي إن أُضيف مستقبلاً. **لا عملية اتصال تلقائية في الخلفية دون إذن المستخدم.**
**منع الاتصالات الخلفية:** لا خدمات تحليل استخدام خارجية، لا إرسال بيانات مستخدم لخوادم، لا رفع تسجيلات ميكروفون، لا خدمات تعرف صوتي سحابية، لا API خارجي لتفسير الآيات، لا API خارجي للبحث اليومي، لا إعلانات أو أدوات تتبع، لا تحديثات تلقائية، لا تنزيلات تلقائية.
**مدير التنزيلات المحلي:** تنزيل عند الطلب، اختيار المحتوى، معرفة حجم كل حزمة والمساحة المتبقية، إيقاف واستكمال، حذف حزم، تحقق من سلامة الملفات، معرفة المحتوى المتوفر دون إنترنت. **لا حذف لمحتوى سبق تنزيله عند تحديث التطبيق.**
**الذكاء الاصطناعي المحلي:** نموذج محلي + محرك استدلال محلي، لا إرسال صوت لأي خادم، لا STT سحابي، عرض حالة النموذج (متاح / غير مثبَّت)، وإن لم يكن محملاً وضّح أنه يحتاج تنزيلاً اختيارياً أول مرة.
**واجهة حالة الاتصال (في الإعدادات):** التطبيق يعمل دون إنترنت، المحتوى المحلي المتوفر، النماذج المثبتة، مساحة التنزيلات، آخر تحديث للمحتوى. لا إزعاج برسائل انقطاع ما دامت الوظيفة المطلوبة تعمل محلياً.
**القاعدة النهائية:** لا تجعل الإنترنت شرطاً لفتح التطبيق أو قراءة القرآن أو الاستماع للملفات المحملة أو التسميع أو الحفظ. لا تتصل بالإنترنت إلا عندما يطلب المستخدم عملية تستلزم الاتصال. المستخدم يثبّت التطبيق ويجهّز محتواه مرة واحدة، ثم يستخدمه لأشهر دون إنترنت، باستثناء رغبته في تنزيل محتوى جديد أو تحديث التطبيق.

## 6. القرارات التسع التي تحتاج موافقتك قبل التنفيذ

1. **PoC محرك التسميع في Flutter:** هل يُستثمر 2–3 أسابيع في إثبات جدوى WebView / إعادة تنفيذ Dart قبل الالتزام بـ Phase 3، أم يُؤجَّل التسميع؟
2. **القراء:** الإعلان بـ **17 قارئاً مكتملاً**، أم اختيار بديلين موثَّقين من قائمة EveryAyah ليصبح العدد 19–20؟ (مصطفى إسماعيل جزئي وإدريس أبكر غير موجود والمشترك غير موجود نقياً — لا يُعرض أي منهم كمكتمل.)
3. **صور مصحف المدينة:** تخطيط نصي أولاً (آمن وموجود في DB) أم استثمار في صور 604 (≈ 600 MB تنزيل اختياري) بعد حسم الترخيص؟
4. **التفاسير الكبيرة:** الانتقال إلى QuranLab بعد قراءة `LICENSES.md` لكل config، أم بقاؤها متصلة عند الطلب مع تخزين مؤقت ≤ 7 أيام؟
5. **التوقيع:** إنشاء keystore إصدار جديد خارج المستودع؟ (تغيير التوقيع = إعادة تثبيت لا تحديثاً تلقائياً للمستخدمين الحاليين.)
6. **ترخيص كود Tilawa نفسه:** MIT للكود (يُقترح) مع إبقاء نسبة Tanzil للمحتوى؟
7. **نموذج التسميع (25–68 MB):** تأكيد أنه تنزيل اختياري عند الطلب ولا يُجبَر عليه المستخدمون الجدد.
8. **معرّف القرطبي 90 + تخزين QF:** إعادة التحقق من 90 في `/resources/tafsirs`، وقرار مصير التخزين المؤقت الحالي (حد 7 أيام أو إيقاف).
9. **Sahih International:** استعمال غير تجاري حرفي مع الإسناد، مع طلب إذن كتابي من Saheeh International / Dar Abul-Qasim؟
